## Notes

- Event payloads are stored twice: indexed columns plus the full envelope in
  `payload_json`. Recovery reads the envelope; columns support queries.
- Checkpoint checksums currently cover the state reference. When the blob store
  lands, the checksum must cover blob content.
- `Journal::append_task_transition` is the only supported status-write path once
  the runtime lands; `TaskRepository::update_status` remains for tests and
  migrations.
