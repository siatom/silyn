## Notes

- SQLx runtime-checked queries are used; no compile-time database is required.
- `sqlx::migrate!` embeds the workspace `migrations/` directory. Adding a
  migration requires a rebuild and a checksum update.
- `Storage::connect` fails fast when FTS5 is unavailable.
- `TaskRepository::update_status` is a plain update. The runtime must use the
  journal path (W1-02) so status and event share one transaction.
