# W7-02a gate: CLI run/experiment reports and the JSON read surface

- Wave: 7

## Scope

Add the reporting surface and lock the scriptable CLI contract:

- `crates/silyn-cli/src/main.rs` gains `silyn report run` and
  `silyn report experiment`, backed only by `silyn-app` read operations and the
  two evaluation JSON documents;
- every read command keeps the global `--json` mode and emits exactly one JSON
  document on stdout; failures keep `{"error":{"class","message"}}` on stderr;
- exit codes stay `0/2/3/4/5`; an unknown run or report path exits 5;
- `docs/architecture/cli.md` documents the command table, the report bundles and
  the deferred `serve` command (W7-02b).

No migration, core, storage, runtime, growth, app, API or eval-suite file was
modified. No dependency was added.

## Command shapes

```text
silyn report run <run-id> [--format json|markdown] [--out <path>] [--json]
silyn report experiment <report.json> [--stats <stats.json>] [--format json|markdown] [--out <path>] [--json]
```

`report run` bundles the `RunRecord`, the journal in sequence order and the tool
ledger. `outcome` is derived from the last `run_verified` event, `failure` from
the last `run_failed` event, and `terminal` from the run status. Markdown is
rendered from the JSON bundle, so the two encodings cannot disagree.

`report experiment` validates `schema_version`, the required identity fields and
the companion's `suite_version`, then merges the report arms with the richer
statistics arms. It emits the raw documents, model id/model_reported, suite
version, split/sealed/seed/backend, suite digests, arm count and arms,
comparisons with the C-A point estimate and interval, thresholds with their
source, verdict, statistics verdict, reason and unauthorized-action count.

A missing `--stats` file falls back to `<report>.stats.json` when it exists; a
missing companion is not an error, but an explicit `--stats` path that cannot be
read is (exit 5).

## Known gap: memory references

`RunOutcome::memory_refs` is not persisted, and `silyn-app` exposes no per-run
memory snapshot. `report run` therefore omits the field instead of emitting an
empty list, which would falsely claim that no memory was injected. Surfacing the
refs needs either a persisted snapshot column or an app read API; both are
outside this task's file scope.
