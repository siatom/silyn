# W7-02b: `silyn serve`

## Scope

- `silyn serve [--addr <host:port>] [--token-env <name>] [--json]`.
- Delegates to `silyn_api::serve`; no duplicate router or auth logic.
- Default address `SILYN_API_ADDR` or `127.0.0.1:7788`.
- Bearer token from `SILYN_API_TOKEN` or the named variable; empty means no
  auth. `/health` is public.
- Non-loopback bind is refused before listening unless
  `SILYN_API_ALLOW_NON_LOOPBACK=1`.
- `--json` prints `{"addr","token_required"}` before serving; Ctrl-C shuts down
  gracefully.

## Tests

`crates/silyn-cli/tests/serve.rs` starts the real binary on an ephemeral port:

- `/health` returns 200 without a token;
- `/v1/agents` is 401/403 without a bearer token and 200 with it;
- `0.0.0.0:0` exits 5 before binding;
- the JSON announcement carries the loopback address and token requirement.
