# W5-03: Evolution CLI and mock golden path

## Scope

- `silyn-app` evolution service over the W5-02 stores: policy bootstrap,
  candidate submission, evaluation attachment, approval, promotion and rollback.
- CLI commands `evolution init|list|show|submit|evaluate|approve|promote|rollback`.
- `PolicyStore::activate` as the only growth addition.
- Evaluation attachment reads the W5-01 report plus its statistics companion;
  metrics are copied, never invented.
- The operator approval path is local and audited; the runtime cannot call it.
- Low-risk promotion still runs the W5-02 gate, including a real rollback drill.

## Commands

```bash
cargo fmt --all --check
cargo test -p silyn-cli -p silyn-app -p silyn-growth
cargo clippy -p silyn-cli -p silyn-app -p silyn-growth --all-targets -- -D warnings
cargo run -p xtask -- verify-acceptance
```

Golden path covered by `crates/silyn-cli/tests/evolution.rs`:

- `evolution init` creates and activates the default policy;
- valid low-risk patch -> `static_checked`;
- forbidden `/tools` patch exits 5 and creates no candidate;
- matching report + stats -> `evaluated`;
- low-risk promotion -> `promoted`, active pointer moves, audit row exists;
- rollback restores the previous pointer; a second rollback exits 5;
- medium/high risk waits, `approve --as` moves it to approved;
- unknown ids exit 5 and usage errors exit 2;
- report/candidate mismatch and missing stats companion exit 5.
