## Notes

- The transport is abstracted, so tests never need a local HTTP server.
- `complete_structured` sends `response_format=json_object`; providers that do not
  support it will return a 4xx, which the runtime surfaces as a permanent error
  rather than silently degrading.
- Usage tokens are parsed from the response; cost is computed by
  `ProviderConfig::cost_usd` when a price table is configured.
- Model id reported by the provider is preserved in `ModelResponse`.
